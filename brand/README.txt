DEVBUS LOGO PACK
================

Brand colours
  Navy          #0B1F3A   (primary text and mark on light backgrounds)
  Burnt orange  #D9480F   (accent: "Bus" and the stripe)
  Ink black     #0A0A0A   (black backgrounds, one-colour print)
  White         #FFFFFF

Typeface: Inter Bold. The wordmark in every file is converted to outlines, so it needs no font installed.

Which file to use
  svg/   Master vector files. Use these for print, signboards, embroidery and anything that must stay sharp.
         primary = navy + orange, for light backgrounds
         reverse = white + orange, for dark backgrounds (black polo, dark app screens)
         black / white = one-colour versions for stamps, receipts, embroidery, single-colour print
  png/   Transparent raster files for documents, social media and websites.
  pdf/   Vector PDFs for print shops.
  icons/ Favicon (favicon.ico, favicon.svg), 192/512 px icons for the web app and Android, 180 px for iOS.

Rules
  - Clear space: keep at least the height of the "D" free on every side.
  - Minimum size: horizontal logo 24 mm / 120 px wide; mark only 8 mm / 32 px.
  - Do not stretch, recolour, add shadows or place the primary logo on busy photos.
  - Use the reverse versions on black or dark photos.

Before you print or register: search the trademark registry for DevBus in Class 39 (and 9, 35, 42 for the app).
Paid app stores may want a 1024 px square icon without rounded corners: use png/devbus-app-icon-square-1024.png.
