VYGO LOGO PACK
==============
India, Let's Go !

Brand colours
  Navy          #0B1F3A   (bus and tagline on light backgrounds)
  Burnt orange  #D9480F   (VYGO wordmark and speed lines)
  Deep orange   #B93A0A   (buttons and hover states in the apps)
  Ink black     #0A0A0A   (one-colour print)
  White         #FFFFFF

All vector files were traced from the approved logo artwork (png/vygo-logo-master-raster-1600x800.png).
The wordmark and tagline are outlines, so no font is needed. Backgrounds are transparent: the white
parts of the bus are see-through, so on a dark background the bus reads as a white line drawing.

Which file to use
  svg/   Master vector files for print, signboards, embroidery and the web.
         vygo-logo-horizontal-primary            navy bus + orange VYGO + navy tagline, for light backgrounds
         vygo-logo-horizontal-reverse            white bus + orange VYGO + white tagline, for dark backgrounds
         vygo-logo-horizontal-black / -white     one-colour versions (stamps, receipts, single-colour print)
         vygo-logo-horizontal-notagline-*        same, without "India, Let's Go !" (use below ~160 px wide)
         vygo-mark-primary                       bus mark alone, navy with orange speed lines
         vygo-mark-navy / -reverse / -black / -white   bus mark in one colour or for dark backgrounds
         vygo-app-icon-rounded / -square         white bus on a navy tile, for app stores and home screens
  png/   Transparent raster files (600 / 1200 / 2400 px wide logos, 512 / 1024 px marks, 192 / 512 / 1024 px icons).
  pdf/   Vector PDFs for print shops (primary, reverse, black, no-tagline primary, mark).
  icons/ favicon.ico (16-64 px), favicon.svg, favicon-16/32/48/64.png, favicon-180.png (iOS home screen),
         icon-192.png and icon-512.png (web app / Android).

Rules
  - Clear space: keep at least the height of the "V" free on every side of the logo.
  - Minimum size: horizontal logo with tagline 140 px / 30 mm wide; without tagline 100 px / 20 mm; mark 24 px / 6 mm.
  - Do not stretch, recolour, add shadows or place the primary logo on busy photos.
  - Use the reverse versions on navy, black or dark photos.

Before you print or register: search the trademark registry for VYGO in Class 39 (and 9, 35, 42 for the app).
App stores that want a square 1024 px icon without rounded corners: use png/vygo-app-icon-square-1024.png.
